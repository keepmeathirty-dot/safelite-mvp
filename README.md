# SafeLite — Community Safety Network

A community safety app that turns your phone into a panic button and connects
you with nearby trusted neighbours and emergency contacts.

## Problem
High crime rates in South African townships and suburbs, expensive private
security, and inefficient WhatsApp-based emergency coordination.

## Solution
- **SOS Button** — one-tap alert with your GPS location
- **Community Alerts** — real-time map of incidents near you
- **Emergency Contacts** — quick access to family, neighbourhood watch, SAPS

## Tech Stack
- React + Vite (frontend)
- Leaflet + OpenStreetMap (map)
- Deployed on Render (static site)
- GitHub for version control

## MVP Scope
Web-only demo. Panic button sends a simulated alert (logged to console).
Real SMS/push notifications and user accounts are planned for v2.
